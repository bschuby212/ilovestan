# Design system — Nike.com style reference (adapted)

Monochrome gallery UI: white walls, product/photography as art, chrome dissolved into the background. No UI accent color. Court storytelling may use environmental color; UI chrome stays Obsidian / Paper White / grays.

## Colors

| Name | Value | Token | Role |
|------|-------|-------|------|
| Obsidian | `#111111` | `--color-obsidian` | Text, icons, strong contrast — not CTA-only |
| Paper White | `#ffffff` | `--color-paper-white` | Page canvas |
| Concrete Gray | `#e5e5e5` | `--color-concrete-gray` | Hairline borders |
| Soft Mist | `#f5f5f5` | `--color-soft-mist` | Secondary surfaces |
| Steel | `#707072` | `--color-steel` | Secondary text |
| Faint Gray | `#9e9ea0` | `--color-faint-gray` | Disabled / tertiary |

## Typography

- UI: Helvetica Neue / Helvetica / Arial — 400 & 500 only — 12–20px body range
- Display: Futura substitute (Montserrat 500) at hero scale ~76px, line-height 1.0
- Never bold/semibold for UI voice

## Shapes

- Buttons / tags: 30px radius pills
- Search / nav soft elements: 24px
- Cards / photos: 0px radius, no shadow
- Elevation via dark/light section rhythm + hairlines only

## Layout

- Max width 1440px for nav/footer content
- Section gap 48px, base unit 4px, compact density
- Full-bleed editorial heroes; product grids on white

## Do

- Monochrome UI only; photography/courts carry chroma
- Pill CTAs: Obsidian-on-white or white-on-Obsidian
- Full-bleed sharp imagery containers

## Don't

- No accent fills, box-shadows, rounded cards, or decorative UI gradients
- No type weights above 500 in the interface voice
