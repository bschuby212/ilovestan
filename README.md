# Stan Wawrinka — a digital tribute

Cinematic, scroll-driven fan tribute to Stanislas Wawrinka.

Visual system follows `DESIGN.md` (Nike.com-inspired monochrome gallery tokens). Motion via GSAP ScrollTrigger + Lenis.

## Stack

- Next.js (App Router) · React · TypeScript · Tailwind CSS v4
- GSAP / ScrollTrigger · Lenis

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
